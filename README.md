## Testament Quest (`/quest/`)
A gamified daily scripture-reading habit: streaks with grace shields, retention quizzes, a virtual sanctuary that grows through Foundation (7 days), Growth (30) and Mastery (90), sequential Testament Quests with artifacts and boss battles, plus Congregation mode with a shared monument, a Fellowship leaderboard and Telegram/WhatsApp encouragement.
